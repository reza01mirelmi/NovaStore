# NovaStore
Nova Store is a backend API for an online jewelry store, built with Node.js, Express, and MongoDB.  
This project includes product management, user operations, and a clean MVC architecture.

## Features
- Add / Edit / Delete jewelry products
- Product categories
- File upload (images)
- MVC Architecture
- MongoDB + Mongoose
- Centralized error handling
- Clean and scalable folder structure

## Project Structure
src/
 ├── controllers/
 ├── routes/
 ├── models/
 ├── middlewares/
 ├── utils/
 ├── config/
 └── app.js

## Installation
git clone <repo-url>
cd nova-store
npm install
npm start

## API Routes Example
GET    /products
POST   /products
GET    /products/:id
PUT    /products/:id
DELETE /products/:id
